# Ручная публикация портфолио на GitHub Pages

Репозиторий: `IlyaIvanovv/IlyaIvanovv.github.io`

Адрес сайта после публикации: `https://ilyaivanovv.github.io/`

## Рекомендуемый способ: исходники и GitHub Actions

1. Распакуйте архив `IlyaIvanovv.github.io-source.zip`.
2. Откройте репозиторий на GitHub и выберите **Add file → Upload files**.
3. Загрузите всё содержимое распакованной папки, включая каталоги `.github`, `app` и `public`.
4. Нажмите **Commit changes**.
5. Откройте **Settings → Pages**.
6. В поле **Source** выберите **GitHub Actions**.
7. Перейдите во вкладку **Actions** и дождитесь завершения `Deploy GitHub Pages`.

После каждого следующего обновления ветки `main` сайт будет пересобираться автоматически.

## Альтернативный способ: готовая статическая сборка

1. Распакуйте архив `IlyaIvanovv.github.io-static.zip`.
2. Загрузите всё его содержимое в корень репозитория, включая каталоги `_next`, `en`, `ru` и файл `.nojekyll`.
3. В **Settings → Pages** выберите **Deploy from a branch**.
4. Укажите ветку `main` и каталог `/ (root)`.
5. Сохраните настройки.

При этом способе после каждого изменения нужно заново собирать и загружать статические файлы.

## Что уже настроено

- автоматическое определение RU/EN при первом открытии;
- ручной переключатель языка;
- прямые адреса `/ru/` и `/en/`;
- WebM 800×450, 20 FPS, 35,75 секунды, около 3,8 МБ;
- подпись `LOOP WEBM · 00:36`;
- fallback-изображение при `prefers-reduced-motion`;
- статический экспорт, совместимый с GitHub Pages.
